# Ryan Cunningham — Professional Portfolio

The polished portfolio version backed up on September 29, 2026, before the experimental animated roadmap redesign.

## Run locally

This is a static HTML, CSS, and JavaScript website. No build step is needed.

Run `python -m http.server 5174` in this folder, then open http://localhost:5174.
